# Hadoop日志异常检测系统 - 最终项目总结

## 项目概述

本项目实现了一个基于Hadoop MapReduce框架的日志异常检测系统，使用LogHub GitHub的HDFS_v3数据集，能够自动识别和分类异常日志。

## 核心成果

### 1. 数据处理
- **数据来源**: HDFS_v3 TraceBench（50个trace文件夹）
- **数据量**: 2,185,618条日志记录
- **处理工具**: DatasetProcessor.java
- **输出格式**: CSV（TaskID, OpName, Description）

### 2. MapReduce实现
- **Mapper**: 解析日志，生成eventName，输出(TaskID, eventName|description)
- **Reducer**: 聚合事件，判断标签，映射eventID
- **输出格式**: label,taskID,eventID1,eventID2,...

### 3. 标签判断规则
```
Normal: Description包含"success:"
Abnormal: Description不包含"success:"且不包含"a user task"
```

## 运行步骤

### 1. 编译
```bash
cd 150/mapreduce
mvn clean package -DskipTests
```

### 2. 上传数据
```bash
hdfs dfs -mkdir -p /user/hadoop/logs/input
hdfs dfs -put 150/data/processed_logs.csv /user/hadoop/logs/input/
```

### 3. 运行MapReduce
```bash
hadoop jar 150/mapreduce/target/log-anomaly-detector-1.0-SNAPSHOT.jar \
  com.hadoop.LogAnomalyDetector \
  /user/hadoop/logs/input \
  /user/hadoop/logs/output
```

### 4. 查看结果
```bash
hdfs dfs -cat /user/hadoop/logs/output/part-r-00000 | head -20
```
