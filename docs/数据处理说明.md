# HDFS日志异常检测 - 数据处理说明

## 一、数据来源

- **数据集**: LogHub GitHub HDFS_v3 TraceBench
- **位置**: `dataset/HDFS_v3_TraceBench/tracebench/`
- **包含**: 50个trace文件夹（NM_、AN_、COM_前缀）
- **数据量**: 2,185,618行日志记录

## 二、数据处理流程

### 1. 数据提取
使用`DatasetProcessor.java`程序从event.csv文件中提取数据：
- **输入**: 各trace文件夹中的event.csv
- **输出**: `data/processed_logs.csv`
- **格式**: TaskID,OpName,Description

### 2. 数据特征
```
TaskID: 任务唯一标识符（16进制字符串）
OpName: 操作名称（如getFileInfo、RPC:getFileInfo等）
Description: 操作描述（包含Success或Error信息）
```

### 3. 标签规则
根据Description字段判断：
- **Normal**: Description包含"success:"
- **Abnormal**: Description不包含"success:"且不包含"a user task"

## 三、MapReduce处理

### Mapper阶段
- 读取processed_logs.csv
- 提取TaskID、OpName、Description
- 生成eventName: OpName+success或OpName+error
- 输出: (TaskID, eventName|description)

### Reducer阶段
- 聚合同一TaskID的所有事件
- 判断标签（normal/abnormal）
- 映射eventName到eventID
- 输出: label,taskID,eventID1,eventID2,...

## 四、文件清单

| 文件 | 说明 |
|------|------|
| data/processed_logs.csv | 处理后的日志数据（2.1M行） |
| data/eventId.txt | 事件ID映射表（2156个事件） |
| mapreduce/src/main/java/com/hadoop/LogAnomalyDetector.java | MapReduce程序 |
| mapreduce/src/main/java/com/hadoop/DatasetProcessor.java | 数据处理程序 |

## 五、运行步骤

### 1. 编译
```bash
cd 150/mapreduce
mvn clean package -DskipTests
```

### 2. 上传数据到HDFS
```bash
hdfs dfs -mkdir -p /user/hadoop/logs/input
hdfs dfs -put ../data/processed_logs.csv /user/hadoop/logs/input/
```

### 3. 运行MapReduce
```bash
hadoop jar target/log-anomaly-detector-1.0-SNAPSHOT.jar \
  com.hadoop.LogAnomalyDetector \
  /user/hadoop/logs/input \
  /user/hadoop/logs/output
```

### 4. 查看结果
```bash
hdfs dfs -cat /user/hadoop/logs/output/part-r-00000 | head -20
```
