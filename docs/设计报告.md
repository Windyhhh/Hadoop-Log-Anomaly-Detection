# Hadoop日志异常检测系统 - 设计报告

## 一、项目概述

### 1.1 项目目标

开发一个基于Hadoop MapReduce框架的日志异常检测系统，能够：
1. 读取HDFS中的日志数据
2. 为每个taskID标注Normal/Abnormal标签
3. 收集同一taskID的所有事件
4. 将eventName映射为eventID
5. 输出格式化的结果

### 1.2 技术选型

- **框架**: Hadoop 3.3.1
- **编程语言**: Java 8
- **构建工具**: Maven 3.x
- **分布式计算**: MapReduce

## 二、系统设计

### 2.1 整体架构

```
输入数据(HDFS)
    ↓
Mapper: 解析日志，提取taskID和事件信息
    ↓
Shuffle & Sort: 按taskID分组
    ↓
Reducer: 聚合事件，标注标签，映射eventID
    ↓
输出结果(HDFS)
```

### 2.2 数据流设计

#### Mapper阶段
- **输入**: 日志行（CSV格式）
- **处理**: 
  - 解析CSV格式的日志
  - 提取taskID、eventName、description、filePath
  - 验证数据完整性
- **输出**: (taskID, eventName|description|filePath)

#### Reducer阶段
- **输入**: (taskID, [eventName|description|filePath, ...])
- **处理**:
  - 遍历同一taskID的所有事件
  - 根据filePath和description判断标签
  - 将eventName映射为eventID
  - 生成最终输出
- **输出**: (label,taskID,eventID1,eventID2,..., "")

### 2.3 标签判断逻辑

#### Normal标签条件
- 文件路径包含"NM_"

#### Abnormal标签条件
- 文件路径包含"AN"或"COM_"
- 且description（转小写）不包含"success:"或"a user task"

#### 优先级
- 如果filePath包含"NM_"，则标记为Normal
- 否则，如果filePath包含"AN"或"COM_"且description不包含特定关键词，则标记为Abnormal
- 默认为Normal

### 3.3 eventID映射

当前实现使用简单的哈希映射：
```java
private int mapEventNameToID(String eventName) {
    return Math.abs(eventName.hashCode()) % 1000 + 1;
}
```

- 读取eventId.txt文件建立映射表
- 使用DistributedCache分发映射文件
- 支持自定义映射规则

## 四、输入输出格式

### 4.1 输入格式

CSV格式，包含以下字段：
```
taskID,opName,description,eventName,filePath
```

示例：
```
C47C9A2D664ACF66,HDFS_Write,File write operation,FileWrite,tracebench/AN_Data_corruptBlk_r_00FDN_30C_1to19B_0to120INT_15RT_5WT/event.csv
```

### 4.2 输出格式

```
label,taskID,eventID1,eventID2,...
```

示例：
```
abnormal,C47C9A2D664ACF66,1,2,3,4,5
normal,D58E0B3E775BDG77,1,2,3,6
```

## 六、性能考虑

### 6.1 优化点

1. **Mapper优化**:
   - 使用StringBuilder而不是字符串拼接
   - 提前验证数据，减少不必要的处理

2. **Reducer优化**:
   - 使用HashMap缓存eventID映射
   - 避免重复计算哈希值

3. **并行度**:
   - 根据数据量调整Reducer数量
   - 使用分区器优化数据分布

### 6.2 可扩展性

- 支持大规模日志数据处理
- 可以添加更多的标签规则
- 支持自定义eventID映射
