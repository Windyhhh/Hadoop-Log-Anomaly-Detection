# Hadoop日志异常检测系统 - 快速开始指南

## 1. 环境检查

### 1.1 检查Hadoop安装

```bash
# 检查Hadoop版本
hadoop version

# 检查HDFS状态
hdfs dfs -ls /
```

### 1.2 检查Java和Maven

```bash
# 检查Java版本（需要Java 8+）
java -version

# 检查Maven版本（需要Maven 3.x）
mvn -version
```

## 2. 编译项目

```bash
# 进入mapreduce目录
cd mapreduce

# 清理并编译
mvn clean package

# 编译成功后会生成：
# target/log-anomaly-detector-1.0-SNAPSHOT.jar
```

## 3. 准备数据

### 3.1 数据格式

输入数据必须是CSV格式，包含以下字段：
```
taskID,opName,description,eventName,filePath
```

### 3.2 示例数据

已提供示例数据文件：`data/sample_logs.csv`

## 4. 运行程序

### 4.1 使用脚本运行（推荐）

```bash
cd scripts
chmod +x run_log_anomaly_detection.sh
./run_log_anomaly_detection.sh
```

### 4.2 手动运行

```bash
# 1. 上传数据到HDFS
hdfs dfs -mkdir -p /user/hadoop/logs/input
hdfs dfs -put data/sample_logs.csv /user/hadoop/logs/input/

# 2. 运行MapReduce任务
hadoop jar mapreduce/target/log-anomaly-detector-1.0-SNAPSHOT.jar \
    com.hadoop.LogAnomalyDetector \
    /user/hadoop/logs/input \
    /user/hadoop/logs/output

# 3. 查看结果
hdfs dfs -cat /user/hadoop/logs/output/part-r-00000
```

## 5. 查看结果

### 5.1 在HDFS中查看

```bash
hdfs dfs -cat /user/hadoop/logs/output/part-r-00000
```

### 5.2 下载到本地

```bash
hdfs dfs -get /user/hadoop/logs/output/part-r-00000 ./result.txt
cat result.txt
```

## 6. 输出格式说明

输出格式为：`label,taskID,eventID1,eventID2,...`

示例：
```
abnormal,C47C9A2D664ACF66,1,2,3,4,5
normal,D58E0B3E775BDG77,1,2,3,6
normal,E69F1C4F886CEH88,1,2,3
```

## 7. 标签说明

- **normal**: 正常任务（文件路径包含"NM_"）
- **abnormal**: 异常任务（文件路径包含"AN"或"COM_"，且description不包含"success:"或"a user task"）

## 8. 常见问题

### Q: 编译失败，提示找不到Hadoop依赖？
A: 确保Maven配置了正确的仓库，或者检查pom.xml中的Hadoop版本是否与系统安装的版本一致。

### Q: 运行时提示"输入路径不存在"？
A: 确保已经将数据上传到HDFS，使用 `hdfs dfs -ls` 检查路径。

### Q: 运行时提示"输出路径已存在"？
A: 删除旧的输出路径：`hdfs dfs -rm -r /user/hadoop/logs/output`

### Q: 如何修改输入/输出路径？
A: 编辑脚本中的 `INPUT_PATH` 和 `OUTPUT_PATH` 变量，或在命令行中直接指定。

## 9. 性能优化

### 9.1 调整Reducer数量

```bash
# 在脚本中添加以下参数
hadoop jar ... \
    -D mapreduce.job.reduces=4 \
    com.hadoop.LogAnomalyDetector ...
```

### 9.2 调整内存配置

```bash
# 设置Mapper内存
export HADOOP_HEAPSIZE=2048

# 设置Reducer内存
export HADOOP_HEAPSIZE=2048
```

## 10. 监控和调试

### 10.1 查看任务日志

```bash
# 查看任务历史
hadoop job -history /user/hadoop/logs/output

# 查看任务详细日志
hadoop logs -applicationId <application_id>
```

### 10.2 查看任务进度

在运行过程中，可以在Hadoop Web UI中查看任务进度：
- NameNode: http://localhost:9870
- ResourceManager: http://localhost:8088

## 11. 清理资源

```bash
# 删除HDFS中的输入数据
hdfs dfs -rm -r /user/hadoop/logs/input

# 删除HDFS中的输出数据
hdfs dfs -rm -r /user/hadoop/logs/output

# 清理本地编译文件
cd mapreduce && mvn clean
```
