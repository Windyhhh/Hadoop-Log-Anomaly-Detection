## 项目概述

### 项目名称
Hadoop日志异常检测系统

### 项目目标
基于Hadoop MapReduce框架，实现一个能够自动识别和分类HDFS日志中异常事件的系统。使用LogHub GitHub的HDFS_v3数据集，处理200万+条日志记录，为每个任务标注Normal或Abnormal标签。

### 核心功能
1. **日志解析**: 从CSV格式的日志文件中提取关键信息（TaskID、OpName、Description）
2. **任务标注**: 为每个任务标注Normal或Abnormal标签
3. **事件聚合**: 收集同一任务的所有事件
4. **事件映射**: 将事件名称映射为事件ID
5. **结果输出**: 生成格式化的输出结果（label,taskID,eventID1,eventID2,...）

### 1.2 Hadoop部署模式

**部署模式**: 伪分布式（Pseudo-distributed）

伪分布式模式特点：
- 所有Hadoop守护进程运行在单个节点上
- NameNode、DataNode、ResourceManager、NodeManager都在同一机器
- 适合开发和测试
- 模拟真实分布式环境

### 3.2 整体方法

**数据流**:
```
event.csv → Mapper → (TaskID, eventName|description)
         → Shuffle & Sort
         → Reducer → (label, taskID, eventID1, eventID2, ...)
```

### 3.3 标注逻辑

**标签判断规则**:
- **Normal**: Description包含"success:"
- **Abnormal**: Description不包含"success:"且不包含"a user task"

### 3.4 Mapper逻辑

```java
// 输入: TaskID,OpName,Description
// 处理:
String taskID = fields[0];
String opName = fields[2];
String description = fields[8];

// 生成eventName
String eventName = opName + 
  (description.contains("success") ? "+success" : "+error");

// 输出: (TaskID, eventName|description)
context.write(new Text(taskID), 
  new Text(eventName + "|" + description));
```

### 3.5 Reducer逻辑

```java
// 输入: (TaskID, [eventName|description, ...])
// 处理:
Set<String> eventNames = new LinkedHashSet<>();
boolean hasAbnormalEvent = false;

for (Text value : values) {
  String eventName = parts[0];
  String description = parts[1];
  eventNames.add(eventName);

  if (!description.contains("success:") &&
      !description.contains("a user task")) {
    hasAbnormalEvent = true;
  }
}

// 映射eventID
for (String eventName : eventNames) {
  int eventID = mapEventNameToID(eventName);
  eventIDList.append(eventID);
}

// 输出: label,taskID,eventID1,eventID2,...
```

### 3.6 运行命令

```bash
hadoop jar 150/mapreduce/target/log-anomaly-detector-1.0-SNAPSHOT.jar \
  com.hadoop.LogAnomalyDetector \
  /user/hadoop/logs/input \
  /user/hadoop/logs/output
```
